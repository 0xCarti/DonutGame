# Golden Hour authored prop library

Generated with Blender 4.5.15 by `tools/unity/build_props.py`. The editable native source is `unity/GoldenHour/ArtSource/GoldenHour_Props.blend`, deliberately outside Unity's Assets directory so Unity imports the explicitly exported FBX files only.

All models use metres, UV coordinates, smooth normals and manufactured edge bevels. Static parts of each prop are joined into one multi-material mesh. The fryer preserves separate `HeatDial`, `SpeedDial`, `Plunger`, `Flipper`, and `Conveyor` meshes; the service bell preserves `BellButton`. `props_manifest.json` records exact exported bounds and geometry budgets. `../Textures/material_manifest.json` describes final shader tints, metallic response and original texture maps. Brand seals use alpha clipping.

## Placement contract

FBX is exported Y-up, -Z-forward. Most prop origins are their bottom contact point. MiniDonut is centred for physical rotation, approximately 65mm across and 26mm high, with a small irregular proof hole and a lighter fried seam. Counter top height is 0.913m. Its waste recess occupies X 1.29 to 1.68m and depth -0.135 to +0.135m, with a floor at Y 0.64m.

Fryer local path in Unity coordinates: hopper (-0.51, 0.24, 0); oil channel (-0.34, 0.24, 0) to (0.38, 0.24, 0); conveyor (0.38, 0.252, 0) to (0.72, 0.395, 0); output slide endpoint (0.89, 0.32, 0). Plunger pivot is (-0.51, 0.4, 0); Flipper pivot is (0.025, 0.267, 0); Conveyor pivot is (0.39, 0.245, 0). Check the imported forward direction when placing the camera and labels.

In the intended operator-facing Unity orientation, HeatDial is centred at (-0.60, 0.346, -0.312), SpeedDial at (-0.49, 0.346, -0.312), with pointer-bearing parts turning around local Z. Blender source pivots are (-0.60, -0.312, 0.346) and (-0.49, -0.312, 0.346). Actual Unity import axis/facing must be checked in-engine; offline Blender previews establish geometry and relative layout only.

Canopy is 4m wide, 1.6m deep, with a 2.934m peak. Its origin is the ground; striped scalloped valance and festoon bulbs face the operator. HangingSign is a separate framed object with the existing Golden Hour brand artwork in its native 3:1 aspect ratio.

The background assets share the same material library. MarketStall has an open serving window, shelves and jars, pitched scalloped canvas roof, framed blank sign and bulb string. ParkBench uses curved metal legs and rounded oak slats. FerrisWheel has a ground pivot, hub at Y 6m, 4.3m wheel radius, twin tubular rims and twelve hanging gondolas; place its root at ground height, not at hub height.

## Authorship and source material

All geometry is original, built specifically for this project by the checked-in Blender script. The general long-channel fryer arrangement follows the user-provided machine reference photo; no manufacturer logo or proprietary mesh is used. Golden Hour brand art, shaker labels, wood, paper, dough and canvas source maps are reused from this repository. Shaker SVG labels were rasterized into native 1024 x 1152 PNGs. Brushed-metal maps are original 1024 x 1024 physical microdetail maps generated by the script.

Native QA renders are written to `playtest-reports/unity-assets/props-fryer.png`, `props-serving.png`, `props-stall.png`, `props-market-stall.png`, and `props-ferris-wheel.png`. The build script's `--verify-only` mode re-imports every FBX and compares dimensions, UV presence and named moving parts with the export manifest; all 18 models pass in `props-fbx-roundtrip.json`. `--skip-renders` regenerates the library without offline rendering.

`tools/unity/preview_workstation.py` creates 1920 x 1080 camera/placement previews from the WorldBuilder source and final FBXs. `--revised` selects the explicitly requested revised camera and authored background props. These are clearly identified as non-Unity previews; Unity material behavior, forward-axis conversion, live controls and performance still require an in-engine pass.
