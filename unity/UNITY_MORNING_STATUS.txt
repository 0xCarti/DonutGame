BUILD AFTER UNITY IS INSTALLED AND LICENSED
From the DonutsGame directory:

powershell -NoProfile -ExecutionPolicy Bypass -File tools/unity/build_windows.ps1

For another editor location, pass -UnityPath "<full path>/Editor/Unity.exe".
The script prepares assets, runs the core checks, then invokes the scene/build
generator. The generator writes Assets/Scenes/Fairground.unity and a Windows
player under builds/unity/windows/GoldenHour.exe. No current file at that path
should be assumed to exist before a successful new build.

Source-only checks without Unity:
powershell -NoProfile -ExecutionPolicy Bypass -File tools/unity/build_windows.ps1 -PrepareOnly

PLAYER VALIDATION AFTER A SUCCESSFUL BUILD
Launch GoldenHour.exe --gh-smoke for an eight-second scene/physics capture.
Launch GoldenHour.exe --gh-acceptance for a real-time automated physical serving
run, fault/gag checks and a full timed Opening Day. It writes screenshots and
result.json under the Unity player's persistent-data Acceptance directory.
Require GH_ACCEPTANCE passed=true, no errors, and inspect the screenshots.
The harness now rejects sustained unreachable hand targets. It is expected to
flag the documented stationary-camera reach issue until that staging is fixed.
Then manually play the loop and review animation feel before calling it ready.
